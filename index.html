Projects.

FinTrack

A full-stack expense tracking app I built from scratch to solve a real problem — I kept losing track of where my money was going. It has secure login, real-time tracking across multiple spending categories, and nine date range presets for filtering. I wired up Chart.js for visualizations so you can actually see your spending patterns at a glance. The stack is React, TypeScript, Node.js, Express, Prisma, and MySQL — containerized with Docker and deployed across Vercel, Render, and PlanetScale. It also has an AI financial assistant built in.

Math Educational App

An Android app I built and published on the Google Play Store using Java and Android Studio. It currently has 57+ monthly active users across four countries — the United States, India, Pakistan, and Kenya — with an 84.9% install retention rate. It was featured in USCA News, which was a nice surprise. The near-zero crash rate is something I'm particularly proud of — it took a lot of usability testing and feedback cycles to get there.

Knowledge Hub

A responsive web platform I co-developed for accessing academic PDF resources at USCA. The focus was on performance — I cut UI load times by 25% through optimized rendering and modular component architecture. Built with React and TypeScript, with a strong emphasis on cross-device usability based on iterative feedback from faculty and students.
